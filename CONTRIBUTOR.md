# Contributing

## 1. Before You Start

- Read [architecture](https://github.com/rootblind/justice-bot/blob/main/docs/architecture.md)
- Read relevant [conventions](https://github.com/rootblind/justice-bot/blob/main/docs/conventions.md)
- Find similar existing implementation
- Identify affected component

## 2. Implementing a Change

- Follow existing patterns
- Reuse abstractions
- Keep changes within their architectural responsibility
- Don't modify protected infrastructure casually

## 3. When the Conventions Don't Fit

- Don't silently break them
- Determine whether an exception is justified
- Document it according to conventions

## 4. Before Submitting

- Verify the implementation
- Check conventions
- Check for unnecessary changes
- Document exceptions
- Explain the change

## 5. Contribution Review

- What changed?
- Why?
- What was tested?
- Were conventions deviated from?


## 6. Minimal workflow

1. Identify the task
2. Read relevant architecture
3. Find analogous implementation
4. Identify existing abstractions
5. Implement smallest appropriate change
6. Check conventions
7. Test / verify
8. Document exceptions
9. Submit for review
